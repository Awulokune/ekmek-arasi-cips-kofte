# EKMEK ARASI CİPS KÖFTE

Dünyanın en çıtır açık kaynaklı sandviçi.

## Gereksinimler
- 1 adet ekmek
- 3-5 adet köfte
- 1 paket cips
- İsteğe bağlı sos

## Kurulum
1. Ekmeği aç.
2. Köfteleri yerleştir.
3. Cipsleri ekle.
4. Ekmeği kapat.
5. Afiyet olsun.

## Bilinen Hatalar
- Cipsler zamanla yumuşayabilir.
- Köfteler ekmekten düşebilir.
- Sandviç beklenenden hızlı bitebilir.
